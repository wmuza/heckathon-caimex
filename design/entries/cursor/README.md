# Mukoti patient

One picture acts out what the helper is asking, and the Shona sentence sits underneath it. The same pictures, drawn small, are how far the visit has gone, so a person who cannot read the number can still see which questions are done.

The picture leads and the words support it. Shona is the line the helper speaks. A quieter English line sits under it for a judge. On a question, six pictures run across the top: a check on each one already asked, a blue ring on the one being asked now.

Motion is slow, and each loop means one thing. A picture eases up into place. Inside it, one verb repeats for about three seconds: a shallow breath, a thermometer rising, a ring moving from the adult to the child, a drop leaving the arm. The microphone breathes outward on the patient's turn, and it is red only while the helper is listening. Nothing flashes or spins. With reduced motion, every picture rests on the frame that already carries the meaning.
